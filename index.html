Garung Guni App: Marketplace & Logistics Microservice API

An end-to-end distributed system created to solve urban recycling coordination. Features a Spring Boot REST API backed by PostgreSQL, automated CircleCI pipelines, Snyk vulnerability scans, and containerized deployment on Heroku.

View GitHub Repositories (ntu-se7-grp3) Access Project Google Drive
Situation

Logistics Fragmentation

Doorstep recycling faces low pickup efficiency and scheduling conflicts for residents and collectors.

Task

Automated System Architecture

Design a scalable backend REST API with persistent storage, automated validation, and secure user management.

Action

Spring Boot & CI/CD Pipeline

Built Spring Boot services using JPA, configured Docker containers, and built CircleCI workflows for testing & deployment.

Result

Zero-Downtime Deployment

Achieved seamless feature releases with automated quality gates stopping builds on failing unit tests or security risks.

Microservice Workflow & Storage Layer

  • Spring Data JPA: Relationships between Users, Schedules, and Item Catalogues.
  • Global Exception Handling: Intercepts validation errors and sends standardized JSON error responses.
  • SLF4J / Logback: Structured file and console logging for monitoring system events.

CI/CD Pipeline Integration

Automated integration and delivery managed through CircleCI & GitHub:

  • Git Branching Strategy: Managed under ntu-se7-grp3 across develop and release branches.
  • Parallel Testing & Security Scans: Maven unit tests run concurrently alongside Snyk container vulnerability checks.
  • Production Deployment: Tested Docker images deploy to Heroku with linked Heroku Postgres services.

Agile Processes & Project Docs

Project documentation and standup tracking:
