Garung Guni: Distributed Recycling & Logistics Platform

An end-to-end full-stack marketplace microservice engineered to streamline doorstep recycling logistics in Singapore. Built with Java Spring Boot, PostgreSQL, Docker, CircleCI automated quality gates, and Heroku deployment.

Docker & Heroku Hosting

Containerized runtime environment backed by Heroku Postgres add-on and CircleCI automated workflows.

// Selected Component Details: REST API Layer

The Spring Boot REST controller uses Dependency Injection to decouple business logic from API contracts. Integrated SLF4J/Logback logs request telemetry and captures runtime exceptions with `@ControllerAdvice` global handlers.

CI/CD Pipeline & Quality Assurance

Git Flow branching triggers automated CircleCI test suites and security scans

1. Git Push
Branch Strategy

Commits pushed to develop branch trigger CI flows; release triggers full CI/CD deployment workflows.

2. CircleCI Runner
Automated Testing

Executes minimum 3 JUnit service layer unit tests. Pipeline halts immediately if any test fails.

3. Snyk Scanning
Security Audit

Runs parallel vulnerability scans on container images and Maven dependencies before build approval.

4. Docker Deployment
Heroku Hosting

Builds Docker image and deploys to Heroku connected with provisioning Heroku Postgres DB.
